# Scout Flyer Builder - Quick Start

## 🚀 Deploy in 5 Minutes

### Prerequisites
- GitHub account (free)
- Vercel account (free, sign up with GitHub)

### Step 1: Create GitHub Repo (2 min)
```bash
cd scout-flyer-builder
git init
git add .
git commit -m "Initial commit"
git remote add origin https://github.com/YOUR_USERNAME/scout-flyer-builder.git
git push -u origin main
```

### Step 2: Deploy to Vercel (1 min)
1. Go to https://vercel.com
2. Click "Add New Project"
3. Select your GitHub repo
4. Click "Deploy"
5. **Wait ~30 seconds**

### Step 3: You're Done! (2 min)
Vercel gives you a live URL: `https://scout-flyer-builder.vercel.app`

Share this link with Scout troops! 🦅
