================================================================================
                          HOW TO DEPLOY (3 STEPS)
================================================================================

STEP 1: Create GitHub Repository
  $ cd scout-flyer-builder
  $ git init
  $ git add .
  $ git commit -m "Initial commit"
  $ git remote add origin https://github.com/YOUR_USERNAME/scout-flyer-builder.git
  $ git push -u origin main

STEP 2: Deploy to Vercel
  Option A (CLI):
    $ npm install -g vercel
    $ vercel
    (Follow prompts, select GitHub project)

  Option B (Web UI):
    1. Go to vercel.com
    2. Click "Add New Project"
    3. Select GitHub repo
    4. Click "Deploy"

STEP 3: Get Live URL
  Vercel will give you: https://scout-flyer-builder.vercel.app
  (URL will be different, based on your GitHub username)
  Share this link with Scout troops!

TIME TO LIVE: ~15 minutes from GitHub push
